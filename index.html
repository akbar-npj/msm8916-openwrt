📦 OpenWrt MSM8916 APK Package Repository

Official package and kernel module (kmod-*) repository feed for Qualcomm Snapdragon 410 (MSM8916) OpenWrt devices.

⚙️ How to Enable on Your Device

Connect to your router via SSH or Web LuCI terminal and add this repository to /etc/apk/repositories.d/customfeeds.list:

echo "https://akbar-npj.github.io/msm8916-openwrt/releases/25.12.5/targets/msm89xx/msm8916/packages/packages.adb" > /etc/apk/repositories.d/customfeeds.list
echo "https://akbar-npj.github.io/msm8916-openwrt/releases/25.12.5/packages/aarch64_generic/base/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
echo "https://akbar-npj.github.io/msm8916-openwrt/releases/25.12.5/packages/aarch64_generic/luci/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
echo "https://akbar-npj.github.io/msm8916-openwrt/releases/25.12.5/packages/aarch64_generic/packages/packages.adb" >> /etc/apk/repositories.d/customfeeds.list

apk update

📥 Installing Packages

Install any driver or application directly:

apk add kmod-usb-net-rtl8152
apk add luci-app-wireguard
