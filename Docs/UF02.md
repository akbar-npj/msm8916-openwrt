# UF02

This page records the OpenWrt profile and hardware validation for the **UF02**
MSM8916 modem stick. It shares the HMUF02-V5 baseband line (same HiMI modem),
so it inherits the A2 power-rail hold, but otherwise follows the common board
baseline.

## Build identity and storage

- Build alias: `uf02`
- OpenWrt device profile: `generic-uf02`
- DTS: `msm8916-generic-uf02` (model `UF02 4G Modem Stick`)
- `SUPPORTED_DEVICES`: `uf02,250605v0s`
- eMMC: 7,569,408 sectors × 512 bytes (4 GB class)
- GPT total sectors: 7,569,408
- Recovery partition: **no** (15-partition layout)

## LEDs

| GPIO | Function | Note |
| ---: | :------- | :--- |
| 72 | `wan` (green) | 4G / internet activity |
| 73 | `wlan` (blue) | Wi-Fi AP activity |

## Reset / failsafe button

- GPIO **23**, **active-high, pull-down** (idle low, press = high).
- A short press inside the first 7 s of boot enters **failsafe**; a 5 s hold
  from a running system performs a **factory reset**.
- Verified on hardware? **Not yet** — declared active-high/pull-down but the
  button flow is unconfirmed. If it does nothing, use the serial `f` key.
- See [Failsafe](../Failsafe/README.md).

## SIM

The UF02 board patch does **not** expose a `sim-presence` / `sim_hotplug`
node, so physical SIM hot-swap is **untested** on this board. The SIM is
selected at boot; see [SIM Hot-Swap](../SIM_HOT_SWAP.md) for how to verify the
line on your unit.

## Profile feature selection

Follows the common baseline:

- failsafe (button, unverified)
- Bluetooth
- WPA3-SAE and multi-SSID
- CPU CPR and the 800 MHz cap
- **A2 power-rail hold** (patch 851) — same HiMI `HIMI_U01_MODEM_V1.0` modem as
  HMUF02-V5, exposed to the same `a2_power.c:1189` quiesce wedge

Leaves these out:

- `qcom-time-daemon` (HMUF02-V5-only)
- recovery partition

## Notes

Modem firmware is identical to stock Android across the MSM8916 line; the ~900 s
modem fatal is AP-side and is mitigated by the A2 hold + Himi-OK gate. See
[Modem Stability](Modem-Stability) in the wiki.
