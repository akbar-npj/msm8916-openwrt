					 a particular link.

					 dev_name cannot be larger

		 <dev_name>              enpoint configuration for a
					 particular link.
					 logical_ep_id are 32bit
					 integers from -1 to 31.
					 Returns the rmnet_mode
					 and egress_dev_name.

					 byte unsigned integer
					 of value none, vnd or
					 bridged. dev_name and
					 egress_dev_name cannot be
					 larger than 15 
					 characters. Returns the
					 status code

rmnetcli newvnd <dev_id>                 Creates a new
					 virtual network device node.
					 dev_id is an int
					 less than 32. Returns
					 the status code

rmnetcli newvndprefix <dev_id> <name_prefix>   Creates
					 virtual network device node.
					 dev_id is an int
					 less than 32. Prefix
					 must be less than
					 15 chars. Returns
					 the status code

rmnetcli getvndname <dev_id>              Get name of
					 network device node from id

rmnetcli freevnd <dev_id>              Removes virtual
					 network device node. dev_name
					 cannot be larger than 15.
					 Returns the status code
