  - "Kernel panic - not syncing:"                               -> MATCH
  - "BUG:" / "Unable to handle" / "watchdog"                    -> MATCH
Only "wwan wwan0: port wwan0at0 disconnected" is NOT covered (no keyword).

=> The pmsg mirror's silence after the hand-off covers every instrumented step
   AND every kernel fault-path banner.  It is not merely "the console went quiet".

8. PROBE MISTAKES RECORDED (Doc 166 §11.3)
-------------------------------------------------------------------------------
* `grep -c PATTERN /dev/kmsg` NEVER terminates -- /dev/kmsg is a stream with no
  EOF, so -c waits forever.  It cost a 20 s ssh timeout this round.
  Use `dmesg | grep -c` (busybox dmesg uses syslog(2) and returns).
  This is IN ADDITION to the already-recorded
  `cat /dev/kmsg | grep PAT | head -N` trap.
* The device's awk needs an anchored pattern for timestamps:
  /^\[ *1840\.3/  (not a bare substring).
