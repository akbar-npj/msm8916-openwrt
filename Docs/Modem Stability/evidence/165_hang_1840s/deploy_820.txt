THE ASYMMETRY THAT MAKES THE FIX SAFE (do not "simplify" it away):
  rx_watchdog_work  -> bam_dmux_rx_watchdog_func() TAKES state_lock (:1309).
                       Every caller of power_off/pm_quiesce HOLDS that lock, so the
                       watchdog is already mutually excluded; the sync cancel added
                       only the deadlock.  It re-checks pc_state, in_teardown and the
                       real line level under the lock at :1315-:1317.
  rx_rearm_work     -> bam_dmux_rx_rearm_work_func() does NOT take state_lock
                       (no state_lock site between :1213 and :1261).  It submits RX
                       buffers, so it MUST be drained synchronously before
                       dmaengine_terminate_sync()/dma_release_channel() below.
