E. SECONDARY DEFECT — the same work item on TWO workqueues (Doc 166 §8)
-------------------------------------------------------------------------------
  687   queue_pm_work(&dmux->tx_wakeup_work);     -> pm_wq
 1922   queue_pm_work(&dmux->tx_wakeup_work);     -> pm_wq
  857   queue_work(system_wq, &dmux->tx_wakeup_work);  -> system_wq

include/linux/pm_runtime.h:62:
	static inline bool queue_pm_work(struct work_struct *work)
	{
		return queue_work(pm_wq, work);
	}

A work_struct must not be queued to two queues: the second queue_work() sees
WORK_STRUCT_PENDING and returns false, so a tx_retry_work-initiated retry can be
silently DROPPED while the item is pending on pm_wq.  Lost-retry bug, not a hang.
Deliberately out of scope for patch 820 so that 820 tests exactly one change.
