# UZ801

This page records the OpenWrt profile and hardware validation for the **UZ801
v3** MSM8916 modem stick. It is the legacy "UZ801" line; the device tree is the
stock `msm8916-yiming-uz801v3.dts` with its LEDs rewired (patch 803).

## Build identity and storage

- Build alias: `uz801`
- OpenWrt device profile: `yiming-uz801v3`
- DTS: `msm8916-yiming-uz801v3`
- eMMC: 7,569,408 sectors × 512 bytes (4 GB class)
- GPT total sectors: 7,569,408
- Recovery partition: **no** (15-partition layout)

## LEDs

| GPIO | Function | Note |
| ---: | :------- | :--- |
| 6 | `wlan` (blue) | Wi-Fi AP activity |
| 8 | `wan` (green) | 4G / internet activity |

UZ801 v3 has **no red LED**, and its WLAN/WAN colour assignment is swapped
relative to the other sticks (WLAN = blue, WAN = green).

## Reset / failsafe button

- GPIO **23**, **active-low, pull-up** (idle high — the *opposite* polarity of
  UF02/HMUF02-V5). This was the source of an early bug where a short press read
  as "permanently pressed" and triggered a factory reset; reverted to
  active-low/pull-up to match the hardware.
- **Failsafe flow is not working yet on UZ801** — the button's idle level and
  response are verified, but do **not** rely on it for recovery. Use the serial
  `f` key. A 5 s hold still performs a factory reset from a running system.
- See [Failsafe](../Failsafe/README.md).

## SIM

No `sim-presence` / `sim_hotplug` node is exposed in the UZ801 profile, so
physical SIM hot-swap is **untested**. See [SIM Hot-Swap](../SIM_HOT_SWAP.md).

## Profile feature selection

Follows the common baseline:

- Bluetooth — **software present, but UZ801 v3 has no Bluetooth antenna**, so
  Bluetooth is unavailable on this board
- WPA3-SAE and multi-SSID
- CPU CPR and the 800 MHz cap
- **A2 power-rail hold** (patch 851) — same HiMI baseband family as HMUF02-V5

Leaves out: HMUF02-V5 thermal maps, `qcom-time-daemon`, recovery partition,
and (effectively) Bluetooth.

## Notes

The "UZ801" name is also the legacy ledger filename for the RF-transplant donor
line; the **unit under test is HMU05/HMUF02-V5**, not UZ801. See
[Modem Stability](Modem-Stability) in the wiki.
